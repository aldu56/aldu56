# ÉLORIA imagery

The files in `products/` are vector placeholders rendered in the brand palette.

To use the official ÉLORIA product photography, drop the photos here and update
the `image` fields in `src/lib/catalog.ts` (and the hero images in
`src/components/site/*`):

| Placeholder                         | Replace with (recommended)                    |
| ----------------------------------- | --------------------------------------------- |
| `products/eloria-smart-mirror.svg`  | `products/eloria-smart-mirror.jpg` (4:5, ≥1600px tall) |
| `products/eloria-smart-comb.svg`    | `products/eloria-smart-comb.jpg` (4:5, ≥1600px tall)   |
| `products/eloria-duo.svg`           | `products/eloria-duo.jpg` (4:5)               |
